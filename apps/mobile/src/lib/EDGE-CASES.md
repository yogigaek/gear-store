# Mobile client logic: edge-case matrix

Each cell names the `*.test.ts` file in this folder and the `describe`/test that covers it. "n/a" means the case does
not apply, with the reason. Coverage gate: `npm run test:cov -w @gear-store/mobile` (src/lib: ≥90% lines and branches;
`part-stills.ts` excepted: Metro's `require()` table of images, which Node cannot load; part-stills.test.ts checks its
entries against the files instead).

Columns: **Bounds** 0/1/max/max+1 · **Bad input** invalid or malicious · **Auth** signed out, refresh failing,
account switch, sign-out mid-request · **Replay** idempotency, resends · **Concurrency** overlapping refreshes/merges ·
**Storage** SecureStore/AsyncStorage throwing or empty · **Time** expiry, timeouts.
