# Web client logic: edge-case matrix

Each cell names the `*.test.ts` file (in this folder unless noted) and the `describe`/test that covers it.
"n/a" means the case does not apply to the module, with the reason. Coverage gate: `npm run test:cov -w @gear-store/web`
(lib/** plus `components/cart/cart-drawer-store.ts` and `components/layout/page-tone.ts`: ≥90% lines and branches).

Columns: **Bounds** 0/1/max/max+1 · **Bad input** invalid or malicious · **Auth** signed out, refresh failing,
account switch, sign-out mid-request · **Replay** idempotency, resends · **Concurrency** two refreshes/merges/tabs ·
**Storage** storage throwing or empty · **Time** expiry.
