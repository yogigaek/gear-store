# Shared contracts: edge-case matrix

Every zod schema's boundaries and rejections, by module. Cells name the `src/*.test.ts` file and test. Coverage gate:
`npm run test:cov -w @gear-store/shared` (all of src: ≥90% lines and branches). Auth, replay, concurrency, storage and
time do not apply to schemas (they hold no state); they are covered where the state lives (apps/api, web and mobile
lib). Expiry formats are covered here (ISO datetimes).

| Module       | Bounds (min−1 / min / max / max+1)                                                                                                                                                                                                                                        | Rejections and malicious input                                                                                                                                                                                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `auth.ts`    | auth: email ≤254 after trim ("takes an email of up to 254 characters"); password 8–128 ("exactly 8 or 128", 7/129 with their messages); login password 1–128; name 1–80 after trim; access token lives ≥1 s; link and refresh tokens exactly 43 base64url                 | auth: email header injection (`\nBcc:`), spaces, `..`, non-strings; demo role only `shopper`/`admin` (case-sensitive); token with `+ / =`, padding, whitespace or newline; unknown role; non-UUID user id; `refreshExpiresAt` not ISO                                                      |
| `address.ts` | address: label 30, recipient 80, line1 5–200, line2 200, city 2–80 (each max+1); postal code exactly 5 digits; mobile numbers 9–14 digits ("shortest and longest")                                                                                                        | address: postal codes `2811`, `281111`, letters, inner space, Arabic-Indic digits; province by exact name only (`bali`, trailing space, `constructor`); 38 provinces in 4 zones; phones with landline, `080…`, `+62 0…`, trailing `;`; saved address with non-UUID id or negative fee      |
| `cart.ts`    | cart: line quantity 0–10 (−1/11/1.5/NaN/∞), finish key ≤40, guest cart ≤50 lines and ≤5 bikes, bike quantity 1–10, merge leftovers may pass 10 but not 0                                                                                                                  | cart: slugs `../etc`, `_`, `--`, leading hyphen, 81 chars; non-UUID bike key or merge key (incl. trailing space, null); `CANNOT_BUILD` on a part line; unknown bike problem; fractional money, negative counts                                                                             |
| `order.ts`   | order: Buy now 1–50 lines of 1–10 (0 lines, 51 lines, 0 and 11 refused); payment window 60 / 10 min (demo); summary itemCount ≥1                                                                                                                                          | order: order numbers in lower case, with 0 or 1, 5 or 7 characters, leading space, trailing newline, path traversal (`/../admin`); non-UUID address or idempotency key; unknown status or refund state; `paymentMethodLabel` for prototype names (`constructor`, `toString`, `__proto__`)  |
| `catalog.ts` | catalog: slug 1–80; page 1–1000; pageSize 1–48; q 1–80 after trim; min = max price; plate ≤3 specs                                                                                                                                                                        | catalog: slugs with capitals, `--`, `_`, space, `/`, `..`, newline, non-ASCII; `inStock=maybe`; `maxPrice=abc`; min > max; 3-digit or 7-digit hex; unknown module; fractional `retryAfter`                                                                                                 |
| `build.ts`   | build: 0 and 12 slots (13 refused), colour key ≤40, quote quantity 1–10 (default 1)                                                                                                                                                                                       | build: slot keys that are not slugs (`frames; DROP`), part slugs with spaces, unknown problem kind, negative price                                                                                                                                                                         |
| `review.ts`  | review: rating 1–5, title 1–80, body 10–2000 (after trim)                                                                                                                                                                                                                 | review: fractional rating, whitespace-only title or body; `publicName` of blank, tabs, many spaces, accented initials; distribution must be 5 counts; unknown reason                                                                                                                       |
| `admin.ts`   | admin: name 2–80, model 1–20, description 10–2000, price Rp 1.000–1.000.000.000, stock 0–100.000, specs 3–20 (label 40, value 80), finishes ≤8, category name 2–40 and description 2–120, sortOrder 0–1000, slot 0–20, list page 1–1000 and pageSize 1–100, tracking 6–40 | admin: duplicate finish keys, bad hex, `Bad Slug`, empty part type (its message), stale edit without ISO `expectedUpdatedAt`, stats range not 7/30/90 or not a number, status `paid`, refund `done`, tracking with space, `;` or `<script>`, empty courier, role `admin`, non-UUID user id |
| `health.ts`  | n/a: two enums                                                                                                                                                                                                                                                            | health: unknown status, missing database                                                                                                                                                                                                                                                   |
